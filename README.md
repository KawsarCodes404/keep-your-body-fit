# keep-your-body-fit

A responsive workout library for browsing exercises, saving favorites, and building a daily training plan.

## Built With

- Next.js App Router
- React and TypeScript
- Tailwind CSS and DaisyUI
- FitLog workout API
- Browser localStorage

## Features

- Browse twelve workouts with images, equipment, muscle groups, and stats.
- Open a detail page with exercise instructions and key specs.
- Add up to five workouts to today’s plan.
- Save workouts for later and view them in a separate tab.
- Sort plan and saved workouts by duration, calories, or rating.
- Track plan minutes and calories, mark workouts done, and remove items.
- Keep plan and saved lists after a page reload.
- Responsive layout for mobile, tablet, and desktop.
