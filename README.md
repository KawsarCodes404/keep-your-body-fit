# keep-your-body-fit

A simple responsible workout library for plan and training muscle plan with varous workout styles and sets. Here user can make plan individually for his daily plan to train his muscle and when needed then he can delete or choose from my-plan page or homepage easily.

## Built With

- Next.js App Router
- React functionality with TypeScript
- Tailwind CSS and DaisyUI
- FitLog workout API
- Browser localStorage

## Features

- This website includes images, muscle group, exercise duration, rating  calories etc.
- This website has details page benefit throudh a user can see every workout plans card dynamically with details also.
- This app can saves the workouts for later view even with a sepate tab also statiically cachewise.
- This app can sort the plan and saved items according to duration, calories and rating.
- User can track their plan according to calories , exercise and minute as well dynamically.
- keep saved the my plan even though page reloads.
- Responsive layout for mobile, tablet, and desktop.
